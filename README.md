# Sprott

Interactive experiments based on J. C. Sprott's dynamical systems and on demonstrations by Owen Maresh on the Diproton YouTube channel.

This repository should keep a clean distinction between published mathematics, our own implementations, and third-party copyrighted code or media.

## Primary sources

### J. C. Sprott

- Strange Attractors: Creating Patterns in Chaos
  https://sprott.physics.wisc.edu/SA.HTM
- Sprott's software archive and redistribution notice
  https://sprott.physics.wisc.edu/SOFTWARE.HTM
- Sprott's publications
  https://sprott.physics.wisc.edu/pubs.htm
- Symmetric chaotic flows gallery
  https://sprott.physics.wisc.edu/fractals/symmetry/
- Book manuscript and supporting material
  https://sprott.physics.wisc.edu/fractals/booktext/

J. C. Sprott's site states that his programs are copyrighted and for personal use except where explicitly identified as freeware. It separately permits noncommercial redistribution of some gallery images with acknowledgement, while requiring permission for commercial use. Do not copy material from the site into this repository merely because it is downloadable.

The mathematical systems, equations, algorithms, and published parameter values can instead be used as references for independent implementations. Attribute the relevant Sprott publication or page when doing so.

## Repository policy

For every external source:

1. **Explicit permissive/open-source license:** mirroring or vendoring is allowed only under that license's terms; retain the license, copyright notices, provenance, and upstream URL.
2. **Explicit redistribution permission with restrictions:** mirror only when this repository's use satisfies those restrictions, and preserve the required attribution and terms.
3. **No license, ordinary copyright, or ambiguous terms:** link only. Do not copy code, prose, images, video, or other expressive material.
4. **Published mathematics:** independently implement equations, algorithms, parameter sets, and mathematical ideas. Cite the original source rather than copying its program text.

This policy intentionally errs toward links when provenance or licensing is uncertain. A later source can be mirrored once its license has been verified.
